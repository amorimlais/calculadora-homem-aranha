🕷️ Calculadora do Homem-AranhaCalculadora completa desenvolvida em Python com interface gráfica usando Tkinter, inspirada no universo do Homem-Aranha.

✨ Funcionalidades
Operações básicas: adição (+), subtração (-), multiplicação (*) e divisão (/)
Operações avançadas: potência (**), raiz quadrada, porcentagem e resto da divisão (%)
Suporte a números decimais
Histórico das últimas 10 operações
Opção de limpar o histórico
Tratamento de erros (divisão por zero, entradas inválidas, etc.)

🎨 Interface
Design moderno com as cores clássicas do Homem-Aranha (vermelho, azul e preto)
Botões grandes e fáceis de usar
Display claro que mostra a expressão e o resultado
Botões extras: √, xʸ, % e Histórico
Visual limpo e organizado

🛠️ Tecnologias
Python 3
Tkinter (biblioteca padrão)

🚀 Como executar
Clone o repositório:
Bashgit clone https://github.com/amorimlais/spiderman-calculator.git

Entre na pasta do projeto:
Bashcd spiderman-calculator
Execute o programa:

Bashpython calculadora.pyNão é necessário instalar nenhuma dependência externa.
